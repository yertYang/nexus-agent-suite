# Changelog

## 0.4.1

- Included the optional icon for copying a Markdown reply, its accessible label, feedback states and styles in the installable package.

## 0.4.0

- Added an offline Chinese component directory with live examples, source and usage notes.
- Updated the light palette and controls; added choices, switches, alerts, collapsible sections, tables and semantic button variants.

## 0.3.0

- Added optional offline Markdown reply formatting, scrollable code and tables, and copy controls.

## 0.2.0

- Refined buttons, form fields, cards and status tags. Desktop browsers with customizable select support also style the open picker.

## 0.1.0

- Added Navi's light palette, compact controls, and accessible CSS components for Workbench and Navi Link.
- Included a component preview, native select icon, and SHA-256 manifest for exact local copies.
