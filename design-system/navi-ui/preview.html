Button 按钮

同一组操作只强调一个主按钮。次要操作用描边，低频入口用文字按钮。

类型与样式

选择按钮可查看反馈。浅色和圆角都可以与语义颜色组合。

尺寸与状态

工具栏使用紧凑尺寸；正在处理的操作同时设置忙碌和禁用状态。

Color 色彩

品牌蓝用于识别和焦点提示。按钮及状态文字使用更深的色值，便于在浅色背景上阅读。

主题色板

Input 输入框

为每个输入框保留可见标签，把错误原因放在字段旁。

文本与校验

试着在项目标识中输入空格，再将它删除。

Select 选择器

选项互斥时使用单选下拉框。可用键盘选择；移动设备保留系统菜单。

表单与工具栏

Choice 选择控件

复选框允许选择多项，单选框用于一组互斥选项。

复选与单选

Switch 开关

开关表示一个可立即切换的设置，支持鼠标、触屏和空格键。

设置状态

Tag 状态标签

用短文字说明状态，颜色作为辅助，标签本身不触发操作。

语义状态

待连接只读已完成待确认运行失败

Card 卡片

将同一对象的名称、状态和说明放在一个有细边框的表面中。

项目摘要

Collapse 折叠面板

把补充说明收进可展开的区域，标题始终可以用键盘操作。

连接说明

连接信息
