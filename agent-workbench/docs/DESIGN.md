# Navi 界面方向

品牌：Navi；浏览器扩展：Navi Link。简洁的几何 N 形标识。

总体布局参考用户提供的 [Dribbble SaaS 设计](https://dribbble.com/shots/27890569-AI-Powered-Sales-Automation-Software)，只借鉴布局层级与组件密度，未使用参考作品素材。聊天输入区优先按用户提供的 Codex 截图：大圆角容器，上方编辑，下方任务入口、固定审批策略、真实模型选择、独立发送/停止。

用户进一步指定整体采用浅色蓝灰主题，并支持桌面侧栏收起与窄屏抽屉。功能必须连接真实页面和审批，不提供装饰性假搜索、假上传或假推理等级。

最终页面移除顶部面包屑横栏和欢迎营销区。桌面侧栏204px/68px切换并仅记录布尔偏好；收起按钮固定在侧栏底部退出按钮下方。状态和刷新在侧栏底部，手机保留独立浮动导航按钮。
