# Navi Link

独立的 Chromium Manifest V3 浏览器扩展。点击工具栏图标打开原生侧栏，在输入框内的底部工具栏选择模型，在对话中按需选择本地项目，使用上箭头发送、方块停止。**普通聊天和浏览器打开、搜索、读取、填写、点击不需要连接 Navi 或 MCP**；在扩展内配置模型 API 即可使用。需要本机文件工具时，再连接可选的 Navi 工作台。也保留 ChatGPT／DeepSeek 网页账号的工具确认模式。

## 用团队网站账号对话

打开侧栏设置 →「团队网站 · 账号对话」。输入团队网站根地址，在网站「我的连接」生成插件配对码，填回侧栏并授权该网站域名。网站与团队侧栏共用本账号的对话记录和服务器模型。配对码两分钟内只能使用一次，账号密码只输入网站；解绑或改密后连接失效。团队页面只开放个人聊天，文件共享及目录任务在团队网站处理。返回 Navi Link 可继续使用原有独立或本机模式。团队模式的接口使用合成模型验证，真实 Chrome 与已部署网站联调尚未验收。

服务器更新团队网站不会更新浏览器里加载的扩展，也不会迁移独立或本机对话。团队站点使用原域名和数据目录时，未过期且未撤销的配对可继续使用。浏览器操作继续使用独立或本机模式；要读这台电脑的项目，仍然连接这台电脑上的 Navi。

## 安装与独立聊天

1. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。启用开发者模式，点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹；ZIP 包须先解压。需要 Chromium 116 或更新版本。固定 Navi Link 到工具栏，点击图标打开侧栏。无需先启动工作台。
2. 点击输入区右下角的「模型与工具设置」图标，选择独立模式，填写模型 API Base URL（以 `/v1` 结尾）和 API Key，点「保存并连接」并允许访问该服务。支持 HTTPS 或本机 HTTP；服务必须提供 `/models` 和 Responses `/responses`，仅支持 Chat Completions 的服务暂不可用。
3. 保存成功后，在输入框内的底部工具栏选择模型，输入消息即可聊天。可直接说“用浏览器打开百度搜索苹果”；每次工具操作仍须批准，读取和交互还会按需申请站点权限。
4. 更新现有安装时，在扩展管理页点 Navi Link 的重新加载，再重新打开侧栏。已配对的旧用户会保留本机模式，可在模型设置切换到独立模式并配置 API。独立模式不需要重启 Navi。

模型 Key 保存在扩展私有本地存储，仅后台向所配置的服务发送；模型配置不会从工作台自动复制。清除模型设置会删除此 Key 和独立对话历史。独立模式历史保存在浏览器会话存储，侧栏关闭再打开可恢复，浏览器完全退出后不保留；更换模型连接会清空独立历史。模型请求超时或后台重启时会明确停止，不自动重复操作。尚未实现逐字显示，收到完整响应后显示回复。

### 思考强度

独立模式下，如果模型服务在 `/models` 的模型条目中声明 `supported_reasoning_efforts` 或 `reasoning_efforts`，输入区会在模型旁显示强度下拉菜单。支持 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`（条目可为字符串或含 `effort` 的对象），只显示服务实际声明的选项。默认强度不额外发送参数；选择后每轮模型与工具续接请求均携带 Responses `reasoning.effort`。切换模型恢复默认强度，运行中不可更改。

未声明能力的模型以及当前本机模式不显示此控件，不根据模型名称猜测支持情况。已有独立连接可重新「保存并连接」刷新模型目录，这会清除独立模式历史。此功能的协议与请求已用合成模型服务验证，不代表所有兼容服务都支持这些字段。

## 可选：连接 Navi 与本机文件

只聊天或操作网页时可跳过本节。本机模式使用工作台自己的模型配置和已授权项目；独立模式不会自动把工具转交给本机服务。需要本机文件时，连接后手动切换到本机模式，再发送请求。

先启动本机 Navi 工作台，在其「连接设置」配置模型，并在「项目与权限」授权目录。

1. 从浏览器工具栏打开 Navi Link，点击输入区右下角的「模型与工具设置」图标，在弹窗展开「本机工具」，点「连接 Navi」。扩展会打开本机 Navi 的确认页。
2. 在 Navi 选择一个已授权项目并确认，然后回到扩展侧栏。若侧栏已关闭，重新点击工具栏图标即可继续配对。无需复制、填写 MCP Token 或项目 ID。
3. 侧栏会显示已连接的项目名称。网页账号模式只为该项目启用 Nexus 实际提供的只读工具；侧栏对话还可在确认页单独勾选「允许浏览器操作」或「允许本机文件操作」。配对请求有效 2 分钟，只能兑换一次。网页工具的 MCP 只读连接有效 7 天；侧栏对话授权有效 12 小时，Navi 工作台重启也需要重新连接。要切换项目，点「更换项目」。

仅操作网页时只勾选「允许浏览器操作」，不用勾选本机文件操作；只操作文件时也不必授予浏览器权限。未开启本机文件操作时仍保留原有项目只读工具，但不能打开 Finder 目录或写入文件。文件写入额外受项目读写策略和逐次审批约束。「允许运行测试」继续独立。旧的合并授权保留原范围；想缩小范围需重新配对，新版不会自动追加另一项权限。

自动配对依赖 Navi 已信任的本机扩展安装标识。本套件当前的安装位置可以直接连接。Chrome 从另一个目录加载扩展时可能赋予新的标识；如果 Navi 提示安装未获配对许可，可使用下文的高级方式。

## 在侧栏对话（本机模式）

你的消息显示在右侧气泡中，Navi 的回复在左侧按正文排版，支持标题、列表、引用、表格和代码块。点回复下方的复制图标可复制原始 Markdown，点「复制代码」只复制该段代码；宽表格和长代码行可横向滚动。

输入框、文件夹和发送／停止图标在同一行，操作图标为 28px；发送等待时用居中的转圈替换箭头，不同时占位。回复复制使用图标，成功显示勾选、失败显示叉号并提供可读提示；正常结束不显示「已完成」标签，错误、审批与停止状态仍保留。Enter／换行提示独立放在输入框下方。模型选择位于输入框内的底部工具栏，使用无边框下拉菜单；设置图标打开居中弹窗，顶部不放模型或设置表单。设置可用右上角关闭按钮、Esc 或点击遮罩关闭，关闭后保留聊天草稿；本机工具默认折叠，切到本机模式时展开。

1. 完成配对并切换到本机模式后，模型选择在输入区，不默认带入示例项目。普通聊天和网页操作可直接开始；需要本地文件时，模型会在对话中请求选择项目，也可点击输入框旁的文件夹图标提前选择。从工作台的实际模型列表中选择模型。如果列表不可用，请在 Navi 工作台的「连接设置」保存并连接 API URL 和 Key。
2. 在底部输入消息，按 Enter 或点上箭头图标发送。Shift + Enter 换行，输入法组字期间不会发送。若 Navi 请求项目工具，侧栏会列出工具和参数；只有点「批准本次」才执行。未勾选操作授权时保持只读；勾选后可使用下文的浏览器和目录工具，以及项目权限允许的文件创建、修改和建目录工具。此授权不启用任意命令执行。
3. 关闭侧栏不会取消后台模型任务；浏览器工具需要侧栏保持打开以领取后续操作，关闭后请在 90 秒内重新打开，否则当前浏览器等待会超时。重新打开会恢复最近的对话和仍在运行的任务；运行时发送位置显示方块图标，点击可停止本轮。运行结束后可开始「新对话」，或用同一模型继续上一轮。如果发送结果未确认，点「检查运行状态」找回任务；草稿会保留。新对话会清除本次项目选择。对话中的项目卡只列出当前连接已授权的项目，选择后自动继续刚才的请求；点「选择其他项目…」会打开 Navi 授权页重新配对，不会直接扩大已有连接的目录范围。
4. 「断开侧栏会话」撤销此侧栏的对话授权。旧版本 Navi 的配对和手动 MCP 连接可继续用于网页工具；新侧栏会检查工作台能力，发现旧后端时阻止发送并明确提示重启，避免界面已更新但执行工具未更新。

## 在对话中操作浏览器和本机文件

独立模式的网页操作配置模型后即可使用。以下本机文件与配对授权仅适用于本机模式。升级本机后端代码后，先停止旧 Navi 工作台再启动（重复双击 `Navi.app` 只会打开已有服务，不等于重启），再在 `chrome://extensions` 重新加载 Navi Link，从侧栏重新连接。在 Navi 确认页分别选择所需权限：**允许浏览器操作**用于网页打开、搜索、读取、点击和填写；**允许本机文件操作**用于 Finder 目录打开、文件创建／修改和建目录。两个选项默认不勾选、彼此独立，回到侧栏分别显示对应授权标签。原来的「浏览器测试」标签现在显示为「已授权项目用例测试」，与日常网页操作分开。

- **“用 Chrome 打开百度，搜索苹果”**：独立模式和本机模式都将这类简单指令作为一次搜索：只需批准一次，即在当前 Chrome/Edge 新建百度搜索标签页。不会额外打开首页、填写、点击或读取网页。打开网址不依赖项目命令权限，首次结果只表示已提交网址；读取搜索结果需要后续的页面读取工具。
- **“读取刚才的页面”“在搜索框填写苹果并点击搜索”**：读取页面会返回文字与可操作元素，再按观察到的元素填写或点击。第一次读取或操作某站点时，批准按钮会申请该站点的浏览器访问权限。只操作当前独立模型连接或本机配对通过 Navi Link 新建的标签页；不控制已有私人标签页、浏览器设置、跨域 iframe、密码和文件上传控件，也不执行模型传入的 JavaScript。页面跳转或元素变化后需重新观察。
- **“在 Finder 打开当前项目目录”** 或 **“打开项目的 docs 目录”**：`navi_open_directory` 核对本机 Runner 登记目录和真实路径后，交给 Finder。仅支持 macOS，路径不能越过当前项目（包括符号链接）。其他本机目录请先在工作台登记为项目并重新配对。
- **“列出目录”“读取 README.md”“创建 notes.md”“修改这个文件”“创建 docs 目录”**：复用 Nexus 实际提供的文件工具。创建和修改还要求项目的读写权限，并保留 Nexus 自身的审批要求。打开目录不需要打开任意文件或执行程序的权限。

简单的百度搜索直接使用扩展的搜索工具，不请求模型规划。独立模式对其他明确的中文网页操作指令（例如“打开百度并读取网页标题”）在首轮使用 Responses `tool_choice` 指定 `navi_browser`，之后恢复自动工具选择。问题、解释、引用和否定语句保持普通聊天。服务没有返回要求的工具调用时，明确报告“未返回浏览器调用，本轮未执行”，不会将普通文字回复标为执行成功。当前本机连接未授权网页操作时，界面显示权限状态，并在这类指令发送前提示重新配对授权或切换独立模式，保留草稿。

侧栏默认隐藏工具提议、审批、启动和结果；有操作记录时，复制和记录图标在回复下方从左到右并排显示。点小钟可展开详情。侧栏沿用浏览器顶部的扩展名称，面板内只显示状态和「新对话」。待批准、失败和结果未知仍会直接提示。每次需要执行的操作单独确认，拒绝不会执行。停止会取消后续调用；已送出的打开、点击或文件操作不能撤销，结果不明时会提示核对，不自动重放。扩展重启后不会自动重复一次点击。浏览器执行使用扩展 API，文件读写使用 Nexus MCP，Finder 使用本机固定目录打开适配；此版本尚不提供整桌面截图、鼠标坐标操作或任意桌面应用控制。

## 在对话中执行测试用例

先在 Navi 确认页为当前项目勾选「浏览器测试」权限。侧栏出现「已授权浏览器测试」后，可发送「用 `tests/login/` 里的用例测试 `https://example.test/login`」。请提供完整的网址和当前项目内的相对目录。

- 文档支持 Markdown、Word `.docx`、Excel `.xlsx`。后两种需要更新后的 Nexus Runner。Navi 显示将要执行的浏览器步骤，批准后从指定网址开始，不越过该来源。报告显示实际的步骤和断言；如有浏览器截图，在同一条报告中点「查看截图」。
- 脚本支持原项目中可运行的 JavaScript Playwright、Python Selenium 和由项目测试启动器运行的 TypeScript Playwright。项目需要已安装的依赖、浏览器与对应执行权限。脚本必须接受固定的目标网址参数；如果运行没有提供与目标匹配的断言报告，会标为「未验证」。
- 部署、缺依赖或项目权限不满足时，侧栏会报告「已阻止」或具体失败。测试中每次观察和执行都需确认。本机模式复用工作台的模型连接；独立模式配置与其分开保存。

## 在网页使用工具

1. 点「复制会话协议」，粘贴到 ChatGPT 或 DeepSeek 网页输入框并加上任务。在已有对话中，先点右下角浮窗的「启用当前对话」，再发送消息。对于新对话，先发一条消息建立会话，再启用扩展；切换页面会结束监听。
2. 如果新的完整回复包含单个 `nexus` 代码块，扩展会提示「待确认」。打开侧栏检查工具名、项目和完整参数，选择「确认执行」或「拒绝」。Navi 配对不会跳过这一步。历史回复、思考过程、普通 JSON Markdown、未闭合的原始围栏和不完整 JSON 均不触发。
3. 查看结果，按需点「追加到草稿」。扩展保留输入框已有内容。检查草稿后自己发送，也可在侧栏复制结果再粘贴。

例如，实际工具列表支持时，可让网页 AI 在最终回复内发出：

`````markdown
```nexus
{"tool":"localbridge_file_read","arguments":{"projectId":"你配置的项目ID","path":"README.md"}}
```
`````

项目 ID、工具名和参数须与侧栏协议一致。即使是只读调用，确认前也请检查项目、路径和参数。结果留在扩展中，只有你点击「追加到草稿」或复制、粘贴时才会进入网页编辑器。发送后，网页服务会收到草稿里的工具输出；请先检查其中是否有不应分享的内容。

## 高级：手动连接

自动配对不可用，或要使用经授权的写入或命令工具时，可展开「高级设置」。如已有配对连接，先点「清除本机连接」，然后使用专用普通 MCP Token（`lb_` 开头）和项目 ID 手动保存。在「检测连接」后，勾选要启用的工具并保存。手动清除仅删除扩展保存的连接；如需撤销令牌，请在本机 Nexus 中操作。配对连接不能通过高级设置改写项目或升级权限。

## 审批、取消与暂停

- 如果 Nexus 返回审批要求，浮窗和侧栏会提供 `http://127.0.0.1:17880/#approvals` 链接；可在本机 Navi 或 Nexus Desktop 决策。审批完成后回到原会话的扩展侧栏，点「审批后重试原调用」。扩展向 Nexus 核验审批，只有状态为 `approved` 才将 Nexus 下发的审批 ID 添加到原参数并重新调用一次。扩展不能作出审批决定，也不接受网页提供的审批 ID。
- 「拒绝」不会调用 Nexus。「停止监听」放弃等待确认的提议；「停止等待」结束本地等待。若请求已发送，Nexus 仍可能已经执行。网页切换、草稿改动或工具响应超时都不会自动重试；工具结果不明时，请先在 Nexus 核实是否执行。
- 每次启用最多监听 45 分钟、执行 12 次。待确认请求 5 分钟后过期。连续 3 次失败或连续 3 次调用和结果相同会暂停，可以检查原因后重新启用。重新启用仍须从手动发送的新消息开始。重开浏览器、刷新或切换会话不会续跑历史请求。

## 网络和权限

独立模式后台只向用户配置的模型服务发送模型请求，禁止重定向，不携带网页 Cookie；聊天内容和批准读取的网页结果会发送给该模型服务。模型服务返回无效 JSON 时只显示格式错误，不显示响应原文。独立聊天不会请求 Navi/MCP。模型域名和网页交互使用按需申请的主机权限。

本机工具相关服务请求仅与本机 Navi 的固定配对和侧栏会话接口（`http://127.0.0.1:17880`）及 Nexus MCP（`http://127.0.0.1:18080/mcp`）通信，拒绝重定向。MCP 请求使用 `X-Nexus-Internal: true` 选择 Nexus 核心路由。该头不替代令牌鉴权。Nexus MCP 2026-07-28 使用 `server/discover` 无会话协商；旧版使用 `initialize` 和可选会话 ID。两者都支持 JSON/SSE 和分页工具目录。浏览器的主机权限不能限定回环端口，服务请求地址与方法在后台固定。浏览器操作另外使用 `tabs`、`scripting` 权限和按网站申请的可选 HTTP(S) 访问权限。网页浮窗仍只注入原有两站；浏览器工具不向目标站点传递本机令牌。

配对地址只携带公开请求 ID。一次性校验值、侧栏会话授权及 MCP Token 都由扩展后台管理，网页脚本、扩展内容脚本、侧栏和会话协议不会收到配对令牌。扩展无需 Nexus 管理 Token。只在两个明确站点的顶层文档注入浮窗；来自页面的消息只能提交待确认提议，不能执行工具，也没有任意网络代理。扩展依赖 Nexus 的工具权限和项目边界，不应为它启用 Nexus 全盘控制。

网页的 DOM 和输入框由第三方维护。如网页改版导致不能识别回复，或无法追加到草稿，可先通过侧栏复制结果。

## 界面样式

扩展复用 Navi UI 基础组件，在 `panel.css` 定义侧栏专属的圆角输入区、紧凑图标与设置弹窗。发送和保存使用深色主按钮，设置表单取消嵌套卡片；基础组件源文件不受这些局部样式影响。输入区的模型选择器保持原生键盘操作，长名称收起时截断，展开后可读全名。扩展自带 Navi UI 0.4.1 的 `ui/` 样式、回复复制图标及许可证，可独立加载和打包，不需要安装 UI 包或联网下载样式。套件维护者请在 `design-system/navi-ui/` 修改共享样式，再从套件根目录运行 `npm run ui:sync`。在扩展目录运行 `npm run ui:check` 可核验本地副本；扩展打包会自动执行此检查。

## 打包

在扩展目录运行 `npm run package`，校验 UI 副本并生成 `dist/navi-link-1.0.0.zip`。打包需要 Node.js 和 `zip` 命令，无需安装 npm 依赖。许可证和来源见 [LICENSE](LICENSE) 和 [NOTICE.md](NOTICE.md)。
